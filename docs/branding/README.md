# Branding

- `marina-residence-icons/`: the full icon set supplied for the app (app icon plus category icons such as plumbing, HVAC, security, in standard and maskable versions, sizes 32 to 512). See its README.txt.
- The app itself uses the files in `web/public/icons/` (any, maskable, apple-touch-icon) and `web/public/manifest.webmanifest`. If you change the app icon, replace those and rebuild.
- The category icons are not wired into the screens yet (the report form now offers only Maintenance and Security).
